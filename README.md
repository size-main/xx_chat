# 聊天系统

基于 C++ 的多人好友单聊系统,支持好友搜索、聊天记录持久化与离线消息。服务端使用 C++ 实现,已提供 Python 客户端(基础功能),C++ / ESP32 客户端规划中。

## 功能特性

### 已实现
- 好友单聊
- 本地好友搜索
- 聊天记录保存(MySQL 持久化)
- 好友离线消息(上线后自动补发)

### 规划中
- [ ] C++ 客户端(GUI)
- [ ] ESP32 客户端(嵌入式)

## 目录结构

```
--Client
    --C++           // C++客户端(未实现)
    --python        // python客户端(实现基础功能)
--ESP32Client       // ESP32客户端(未实现)
--loadServer        // (C++)服务端(已实现基础功能)
    --mysqllib      // 编译的Qt6连接MYSQL的dll文件，如果使用MSVC并且MYSQL安装默认C盘以及版本和我一致可以直接放在生成的exe同级目录下
--chat_server       // MYSQL 数据库脚本与配置
--README.md
```

## 技术栈

| 模块 | 技术 |
|---|---|
| 服务端 | C++ / Qt 网络库 [按实际修改] |
